## Implementation Details

### 1. Backend: New Aggregated Query & Model

**File**: `backend/internal/client/model.go`
- Add `ClientWithDetails` struct with fields: `ID`, `Name`, `CNPJ`, `ProjectName`, `ProjectStatus`, `ProjectIsActive`, `Responsible`, `CompletedAgendas`, `TotalAgendas`, `CreatedAt`
- Use `*string` for nullable project fields, `int` for agenda counts

**File**: `backend/internal/client/service.go`
- Add `GetClientsWithDetails()` function
- SQL query using LEFT JOIN with a subquery for latest project per client:
  ```sql
  SELECT c.id, c.name, c.cnpj, c.created_at,
         p.name AS project_name, p.status AS project_status, p.is_active,
         u.email AS responsible,
         COUNT(m.id) FILTER (WHERE m.status = 'completed') AS completed_agendas,
         COUNT(m.id) AS total_agendas
  FROM clients c
  LEFT JOIN LATERAL (
      SELECT * FROM projects
      WHERE client_id = c.id
      ORDER BY created_at DESC LIMIT 1
  ) p ON TRUE
  LEFT JOIN meetings m ON m.project_id = p.id
  LEFT JOIN LATERAL (
      SELECT analyst_id FROM meetings
      WHERE project_id = p.id
      ORDER BY scheduled_at DESC LIMIT 1
  ) latest_m ON TRUE
  LEFT JOIN users u ON u.id = latest_m.analyst_id
  GROUP BY c.id, c.name, c.cnpj, c.created_at, p.name, p.status, p.is_active, u.email
  ORDER BY c.name ASC
  ```

**File**: `backend/internal/client/handler.go`
- Update `ListClientsHandler` to call `GetClientsWithDetails()` instead of `GetAllClients()`
